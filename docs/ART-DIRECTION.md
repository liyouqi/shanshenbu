# 《闪身步》视听方向（ART-DIRECTION）

- **日期**：2026-11-08
- **范围**：阶段一的视听识别要求；玩法以 `GDD.md` 为准，资源组织与播放方式见 `TECH-DESIGN.md` 第7.1节。

当前仓库此前未包含本文件。本次仅记录已明确的识别元素与喊招修正，不补写未提供的舞台、人物、动作或UI设计细节，不改变其他已确认方案。

## 1. 第一阶段核心识别元素

**蓝色舞台、人物造型、标志性动作、原视频真实喊招声音同等重要。** 原声是第一阶段体验的组成部分，不是可以留到以后或用合成声音替代的装饰。

蓝色舞台、人物造型与标志性动作延续已确认的视觉方向；本次不新增配色参数、服装、布局或动作方案。真实喊招来自原始《安徽花鼓灯（男班）》教学视频，保留教学演示中的声音辨识度与节奏，例如“闪身步！”。

第一阶段所有动作资源必须围绕统一角色母版接入，禁止动作间人物造型漂移。

## 2. Player与CPU的声音表现

- **Player**：使用对应招式的真实原声，保留音色、语调、停顿与喊招节奏；不明显变调，不重新录制，不用AI生成配音或设备TTS替代。
- **CPU**：使用同一套原声素材，允许轻微音高、音色或EQ差异，让玩家听出招式由对手发动；不破坏原声辨识度与节奏，不做明显电子音、机器人音或卡通尖叫。
- **听感要求**：同一角色连续出招避免严重叠音，双方同时释放技能时尽量仍能分辨来源。CPU处理方案通过实际听感测试确定，不在文档中提前固定参数。
- **音画关系**：只有技能成功发动才喊招；声音不驱动命中或改变技能时长。喊招与破空、命中、受击等SFX分别管理。

项目方已处理相关素材使用授权。此前“不要直接使用原视频原声”的要求作废，首版必须使用真实原声。

## 3. 素材现状与后续制作要求

仓库尚未提供原始视频或喊招音频，现有合成短音效不是原视频原声；原声提取、CPU版本制作与游戏接入均未完成。旧设备语音占位代码尚未修改，不能作为新要求已完成的证据。

后续从原始素材提取对应招式片段，尽可能保留清晰人声，裁去前后无关声音，避免突然截断或明显爆音，保留原始停顿和节奏。CPU轻微处理版本从同一片段制作，优先预制两套文件由Phaser播放，不建设复杂实时音频处理系统。

素材需求、预期目录和资源键统一见 `TECH-DESIGN.md` 第7.1节。本次只更新文档，不开始提取、变音、音效制作或代码接入。
