# 《闪身步》动作覆盖包 V0.3（占位资产）

本包用途：**尽快把完整一局涉及的动作表现接上**，不是最终美术，也不是完成透明度验收。

## 本包内容

- `animations/*.gif`：用于人工查看各动作动态效果，不建议直接作为正式游戏运行素材。
- `spritesheets/*.png`：每个动作一张横排 RGBA 图，单帧固定 **400×370**。
- `frames/<action>/*.png`：单独 PNG 帧。
- `animation_manifest.json`：动作名、帧数、帧时长、loop 参数。
- `previews/action_overview.jpg`：各动作代表姿势速览。

## 状态说明

- **已有试制保留：** `dodge`、`kick`。`kick` 使用上一版修复帧，但已知细白边和局部裤脚误抠依然存在。
- **这一轮新补的临时动作：** `idle`, `walk`, `jump`, `crouch`, `guard`, `punch`, `hit`, `ko`, `nineRings`。
- **必须诚实标注：** 本次新补动作主要由已认可Q版角色姿势变形、平移、旋转和复用形成；`punch` 和 `nineRings` 尚不是准确的动作绘制。只用于让整个游戏状态有可见反馈，不能作为美术最终版。

## 接入约束

1. 仅替换缺失的表现层动画；若现有程序动画更好，则保留程序动画。
2. 不修改Combat Core、技能伤害/位移或数值配置。
3. 角色真正的世界坐标和跳跃高度由游戏控制，**不要因为Sprite姿势中的变化二次平移角色**。
4. 基于当前战斗事件切换动作；人物自动面向对手由已有代码负责。
5. `walk/idle`循环，其他状态动作按manifest。`ko`最后一帧可停留。
6. 已知白边/透明问题记为P1资产清理任务，不阻塞这个覆盖包的测试。
