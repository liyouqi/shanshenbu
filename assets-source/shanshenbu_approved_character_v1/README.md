## 关键工程契约

- 战斗角色位置、血量、命中、冷却均由现有Combat Core控制，图片不参与数值计算。
- 纹理图片透明，动画帧可替换，游戏操作不依赖具体文件名。
- 后续需先制作可活动的分件角色，然后在同一母版上完成所有动作。
- 原教学视频的动作和原声为对照依据；本包不包含完整视频音轨或正式逐招音频。
