# 闪身步 / shanshenbu

**一个打开网页就能玩的、魔性好笑的2D横版格斗小游戏。**

- **产品长期方向**：轻社交。朋友之间用夸张舞步对打、分享趣味内容；不是专业竞技格斗。
- **当前开发范围**：**单机人机对战**；无账号、无服务器、无选择界面。
- **技术基线**：**Phaser 4.2.1 + TypeScript + Vite**；手机横屏虚拟摇杆/技能按钮 + PC键盘。
- **工程原则**：简单、可玩、可调。规则/数值与输入、动画、皮肤、音效、UI分离；不为未来功能过度设计。
- **文档日期**：2026-11-08；版本V1.2（进度与产品路线同步，阶段一玩法基线不变）。

## 当前进度与工作重点

**当前处于阶段一的可玩原型打磨期。** 功能框架已经实现：

- 2D横版单机人机对战；移动、跳跃、下蹲、格挡、闪避、穿身和自动转向。
- 普通攻击、闪身步、浪子踢球、九连环；简单AI、血量、计时、胜负结算和重赛。
- PC键盘、手机虚拟摇杆与多指触控、暂停恢复；基础动画、临时UI、特效和音效。
- 已针对此前反馈的卡顿完成显示优化，包括减少重复界面更新、缓存静态背景和移动插值；目标设备上的实际效果仍需试玩确认。

**当前重点**：正式人物与场景美术、标志性技能动画与打击反馈、正式喊招配音与音效打磨、UI与交互视觉设计、真实手机体验验证、趣味性与重玩意愿验证，以及Web正式部署。UI和美术独立推进，不改动既有战斗规则。

此前开发反馈记录：19项逻辑与插值测试、生产构建、Chrome桌面及移动端模拟回归通过。**这不等于真实手机兼容性已完成验收**；真实iPhone/Android、Safari/Firefox、声音听感与重玩意愿仍待验证。项目尚未正式部署。

## 三阶段产品路线

| 阶段 | 目标与范围 | 状态 |
|---|---|---|
| **一：单机人机对战** | 打开网页即玩，无注册、角色选择和复杂菜单；完成轻松、魔性、有趣的2D横版Flash风格小游戏 | **当前阶段**，功能框架已实现，集中打磨视觉、动画、配音、UI与体验 |
| **二：异步PvP / 离线分身对战** | 挑战朋友或实力接近的陌生玩家的离线角色；本地战斗由AI控制对手，服务器保存快照与挑战记录 | **未来优先社交方向**，尚未进入开发 |
| **三：轻社交成长系统** | 等级经验、操作习惯形成的AI风格、战报与复仇、自定义外观、成就称号和分享 | **未来规划**，具体规则未定，尚未进入开发 |

未来阶段尽量复用现有Combat Core、AI Controller、技能配置和动画表现；阶段一仍是纯前端Web单机项目。实时PvP属于非优先事项。完整后续方向与待定问题集中记录在 [`docs/TODO.md`](docs/TODO.md)，不为未来规划提前建设系统或改变当前战斗数值。

## 第一阶段必须做到什么

1. 打开网页直接进入战斗场景；首次**有效玩法输入**后开始计时和AI行动，该输入本身不丢失。
2. 玩家能够左右移动、跳跃、下蹲、自动面向对手，使用拳/闪/踢/必四个按钮；电脑使用简单相同规则。
3. 可以命中、格挡、闪避、扣血、KO或时间结束判输赢；一局结束立即重玩。
4. 有基础人物动作、原创技能语音/命中音效，手机横屏多指触控与PC键盘都可用。
5. 原型能在代表性真实设备中运行，后台暂停恢复正常；无声或无震动不影响战斗。

功能完成与体验完成分别验收：能正常打完一局、没有明显操作和规则错误是功能标准；闪身、踢击、喊招和受击反馈是否有趣，玩家是否愿意主动再玩一局，必须通过实际试玩判断，不能由文档或代码测试代替。

## 给开发工具/AI编码助手的执行准则

- **先读GDD、TECH-DESIGN、balance.json**，再写代码；如发现冲突先标出，不要自行扩张需求。
- 第一优先级是**可玩的简单人机闭环**，不是大量人物、漂亮UI或专业格斗判定。
- 战斗规则用纯TypeScript；Phaser只负责显示与输入/音频适配。不让渲染对象参与权威伤害计算。
- 动画首选程序分件+少量夸张特效；AI帮助生成角色部件与代码，不要求开发者手绘几十帧。
- 允许临时丑陋占位图，先把移动、命中和声音打通，再做角色美术和正式UI。
- 若确实需要调整已确认需求，更新对应文档；如果只是数值调节，优先改`balance.json`。
- 不擅自加入联网、换脸、数据库、UI框架、复杂插件、3D引擎或额外商业化模块。

## 本地运行原型

需要 Node.js 22.12+（本次使用24.11.0）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。手机可与电脑连接同一局域网，打开终端显示的 Network 地址；需要允许本机防火墙访问。手机使用横屏。

- `A/D` 或方向键左右移动，`W`跳、`S`蹲；`J/K/L/U`依次为拳、闪、踢、必杀。
- 按住远离对手的方向格挡。`Esc`暂停，结算后按`Enter`/空格或点击按钮重赛。
- 手机上的左摇杆与右侧技能按钮支持同时触控；声音与暂停入口在右上角。

```sh
npm test          # 纯战斗逻辑测试
npm run build    # TypeScript检查与生产构建，输出dist/
npm run preview  # 预览生产构建
```

浏览器回归使用 `npm run test:browser`，需先运行开发服务器。macOS默认使用已安装的Chrome；其他环境可设置 `BROWSER_EXECUTABLE` 指向Chromium浏览器，或安装Playwright Chromium。`GAME_URL`可覆盖默认地址 `http://localhost:5173`，截图输出到忽略目录 `.test-artifacts/`。

当前图形由代码绘制，短音效可通过 `python3 scripts/generate-sfx.py` 重新生成；喊招暂用设备提供的中文语音合成，没有可用中文语音时保留字幕与音效。正式角色美术和原创录制配音尚未制作，可选振动尚未接入。
